근무 유형 설정▾

이름은 자유롭게 (주간/Day/D 등). 역할(주간·야간 등)만 맞게 지정하면 자동 계산에 활용됩니다.

조별 근무 패턴 설정▾

조 이름을 원하는 표현으로 바꾸고, 아래 아이콘을 눌러서 순서대로 근무를 쌓으세요. 각 조 카드의 ⭐로 나의 근무조를 지정할 수 있어요.

알람 설정 (근무 시작 기준)▾

안드로이드 앱(APK)에서는 근무표에 맞춰 실제 알람이 울려요. 앱을 완전히 꺼놔도 울려요 (백그라운드 실행 필요 없음). 웹 화면에서는 미리듣기만 가능해요. 반복 횟수를 정하면 3분 간격으로 다시 울려요.

🔄 기기 간 동기화▾

아이폰과 안드로이드에서 같은 코드를 입력하면 실시간으로 데이터가 서로 반영돼요.

📅 구글 캘린더 연동▾

전달·이번달·다음달치 근무표와 등록한 일정을 구글 캘린더에 자동으로 올려줘요. 알람 켜놓은 근무는 구글 캘린더 알림으로도 울려요. (아이폰/PC 웹 화면에서만 사용 가능해요)
